# NLP Chatbot Using Python and Machine Learning

## Overview
This project implements a simple intent-based chatbot using Python and machine learning. It classifies user messages into predefined intents and generates appropriate responses.

## Technologies Used
- Python
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression

## Features
- Text-based conversation
- Intent classification
- Predefined responses for common queries
- Simple interactive command-line interface

## How to Run
1. Install Python.
2. Install the required library:
   `pip install scikit-learn`
3. Run the chatbot Python file.
